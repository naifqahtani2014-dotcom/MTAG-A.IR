MTAG | منظومة الطيران العالمي
================================

This is a local-only fictional Roblox license management portal.

Node.js:
v24.18.0

Run:
npm run dev

Then open:
http://localhost:3000

Admin:
http://localhost:3000/admin

Default admin credentials are stored in .env:
Username: admin
Password: MTAG-Admin-2026

IMPORTANT:
- The Discord webhook is stored in .env and is not exposed to frontend code.
- Do not publish .env or upload it to GitHub.
- This project uses only Node.js built-in modules, so no npm install is required.
- Data is stored locally in data/licenses.json and data/audit.json.
- The site is fictional and for Roblox roleplay.
